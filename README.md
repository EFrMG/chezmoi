# Personal Dotfiles

To be cloned at `~/.local/share/` under the name of `chezmoi`

```bash
gh repo clone EFrMG/chezmoi ~/.local/share/chezmoi
```

---

## Contents

You might find some interesting scripts [in here](./dot_local/bin); they create to-do files interactively, clear the trash on all drives, extract from most filetypes, initialize Tmux to have a single session as primary quickly...

There are some hardcoded Catppuccin values for themes here and there, although not for the waybar given that I like it to contrast when the battery is running low or high.

> [!NOTE]
> A lot of configs are meant to be used on the Omarchy Linux distribution.
